# Hodgkin-Huxley Sensitivity Analysis

This is a version of the Hodgkin-Huxley sensitivity analysis codebase, organized into a clean, modular package structure.

## Overview

The codebase performs global sensitivity analysis on the Hodgkin-Huxley neuron model using JAX/diffrax for simulations and SALib for Sobol sensitivity analysis. It generates publication-quality figures showing time-dependent sensitivity indices.

## Package Structure

```
├── config.py              # Configuration constants (no JAX import)
├── parameters.py          # Parameter definitions and LaTeX names
├── sampling.py            # SALib/Saltelli sampling utilities
├── sim_core.py            # JAX/diffrax simulation engine
├── sim_io.py              # Chunking and disk I/O utilities
├── analysis.py            # Trace categorization and Sobol analysis
├── plotting.py            # All matplotlib plotting functions
├── pipeline.py            # End-to-end workflow orchestration
├── replot_cli.py          # CLI for replotting from saved data
├── params_boot.csv        # Bootstrap parameter statistics (input)
├── requirements.txt       # Python dependencies
└── README.md             # This file
```

## Installation

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Ensure JAX is properly configured for your hardware (CPU by default).

## Usage

### Running the Full Pipeline

To run the complete sensitivity analysis:

```bash
python pipeline.py
```

This will:
- Load parameters from `params_boot.csv`
- Generate Saltelli samples (N=8192 by default)
- Run JAX simulations in chunks
- Filter for single AP traces
- Perform Sobol sensitivity analysis
- Generate all figures
- Save results to CSV files

### Customizing the Pipeline

```bash
python pipeline.py --N 4096 --chunk-size 10000 --I-amplitude 20.0
```

Available options:
- `--N`: Base sample size (default: 8192)
- `--chunk-size`: Simulations per chunk (default: 12500)
- `--I-amplitude`: Current injection amplitude in μA (default: 30.0)
- `--bootstrap-file`: Path to parameter bootstrap file
- `--skip-simulation`: Use existing simulation chunks if available
- `--skip-filtering`: Use existing filtered data if available

### Replotting Figures

To regenerate figures from saved data without rerunning simulations:

```bash
python replot_cli.py
```

Or from a different directory:

```bash
python replot_cli.py --data-dir /path/to/results --output-dir /path/to/figures
```

Available options:
- `--data-dir`: Directory containing data files (default: current)
- `--output-dir`: Directory to save figures (default: same as data-dir)
- `--skip-traces`: Skip voltage trace plots
- `--skip-sobol-time`: Skip time-dependent Sobol plots
- `--skip-sobol-bars`: Skip bar chart Sobol plots
- `--skip-combined`: Skip combined A4 layout

## Required Data Files

The replotting script requires these files (generated by the pipeline):

- `time_vector.csv` - Time points
- `param_names.txt` - Parameter names (one per line)
- `mean_V.csv` - Mean voltage traces
- `S1_time.csv` or `S1_time_with_headers.csv` - First-order Sobol indices
- `ST_time.csv` or `ST_time_with_headers.csv` - Total-order Sobol indices
- `all_V_sample.csv` - Sample voltage traces (optional, for trace plots)

## Output Files

### Data Files
- `mean_V.csv`, `std_V.csv` - Statistics
- `S1_time.csv`, `ST_time.csv` - Sobol indices
- `S1_time_with_headers.csv`, `ST_time_with_headers.csv` - With parameter names
- `all_V_sample.csv`, `all_V_sample_transposed.csv` - Sample traces
- `time_vector.csv`, `param_names.txt` - Metadata

### Figures (PNG + PDF)
- `voltage_traces.png/.pdf` - Sample voltage traces with mean
- `voltage_traces_with_stimulus.png/.pdf` - Traces with stimulus period
- `sobol_S1.png/.pdf` - First-order sensitivity indices over time
- `sobol_ST.png/.pdf` - Total-order sensitivity indices over time
- `sobol_S1_70ms.png/.pdf` - First-order indices at specific time points
- `sobol_ST_70ms.png/.pdf` - Total-order indices at specific time points
- `sobol_combined_A4.png/.pdf` - All Sobol plots in A4 layout

## Key Features

- **JAX Acceleration**: Vectorized simulations with JIT compilation
- **Memory Efficient**: Chunked processing and memory-mapped I/O
- **Parallel Analysis**: Multi-process Sobol analysis
- **Publication Quality**: LaTeX-formatted parameter names and professional styling
- **Modular Design**: Clean separation of concerns for easy maintenance
- **Reproducibility**: Configurable parameters with validation

## Technical Details

- **Simulation Engine**: JAX/diffrax with adaptive ODE solving
- **Sensitivity Analysis**: Saltelli sampling with SALib
- **Data Processing**: Memory-mapped arrays for large datasets
- **Visualization**: Matplotlib with publication-quality formatting

## Performance Notes

- First simulation chunk is slower due to JIT compilation
- Memory usage scales with chunk size and sample count
- Sobol analysis is I/O bound; more processes help up to ~8 cores
- Transposed data format dramatically speeds up sensitivity analysis

## Troubleshooting

- **JAX Issues**: Ensure proper JAX installation for your hardware
- **Memory Errors**: Reduce chunk size or N
- **Missing Data**: Run pipeline first before replotting
- **Slow Performance**: Check JAX backend and available RAM
